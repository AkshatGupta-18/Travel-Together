# Travel Together 🌍✈️

A social travel platform where users can connect, share their travel experiences, and explore posts from other travelers. This project is currently under active development, with new features being added regularly.

## 🚀 Current Features

* Secure user authentication (Sign Up / Login)
* User profile management
* View other users' profiles
* Create and share travel posts
* Browse posts from other users
* Responsive and modern user interface

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* MongoDB
* Cloudinary 

### Tools & Technologies

* Git
* GitHub

## 📌 Upcoming Features

* Like and comment on posts
* Follow/Unfollow users
* Search users and destinations
* Edit/Delete posts
* Notifications
* Improved profile customization
* Enhanced mobile responsiveness

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Travel-Together.git
```

Navigate to the project:

```bash
cd Travel-Together
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```
