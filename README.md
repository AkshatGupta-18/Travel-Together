# Travel Together 🌍✈️

A social travel platform where users can connect, share their travel experiences, and explore posts from other travelers. This project is currently under active development, with new features being added regularly.

## 🚀 Current Features

* Secure user authentication (Sign Up / Login)
* User profile management
* View other users' profiles
* Create and share travel posts
* Browse posts from other users
* Responsive and modern user interface

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* MongoDB
* Cloudinary

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Travel-Together.git
```

### 2. Navigate to the project

```bash
cd Travel-Together
```

### 3. Install dependencies

#### Backend

```bash
cd backend
npm install
```

#### Frontend

```bash
cd ../frontend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the `backend` folder and add the required environment variables (MongoDB URI, JWT Secret, Cloudinary credentials, etc.).

### 5. Run the Backend

```bash
cd backend
npm start
```

### 6. Run the Frontend

Open a **new terminal** and run:

```bash
cd frontend
npm run dev
```

The frontend and backend should now be running locally.
